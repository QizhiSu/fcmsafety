FCMSafety fcmsafety-v2 实习生开发指南

食品接触材料安全评估 R 包 · AI 辅助开发版 · 必读

第一步：账号与仓库准备

1.1 注册 GitHub 账号

  1. 打开 https://github.com，点击 Sign up
  2. 填写用户名、邮箱、密码，完成验证

1.2 Fork 仓库

  1. 打开 https://github.com/QizhiSu/fcmsafety
  2. 点击右上角 Fork 按钮
  3. 等待几秒，页面跳转到「你的账号/fcmsafety」，此时你拥有了自己的可读写副本
⚠️ 注意：这个项目有两个分支，实习生只需要关注 fcmsafety-v2，不要动 main 分支。

第二步：配置本地开发环境

2.1 安装 Git

  • Windows：下载 Git for Windows（安装时选默认选项即可）
  • macOS：运行 xcode-select --install 或从 git-scm.com 下载
⚠️ Windows 用户注意：安装 Git for Windows 后，会附带 Git Bash（一个类似 Linux 的终端）。本指南中所有 git 命令都在 Git Bash 里运行。打开方式：开始菜单 → 搜索 "Git Bash" → 回车。

2.2 安装 R

访问 https://cran.r-project.org/，下载适合你系统的版本并安装。

2.3 安装 VS Code（推荐）

不需要安装 RStudio，VS Code 完全够用，而且更适合 AI 辅助开发：

  1. 下载安装 VS Code
  2. 安装 R Extension Pack 扩展（VS Code 侧边栏 → 扩展 → 搜索"R Extension Pack" → 安装）
  3. 打开项目：File → Open Folder → 选择 fcmsafety 目录
⚠️ Windows 用户：VS Code 内置终端默认是 PowerShell，可以改成 Git Bash 更方便。操作：Ctrl+Shift+P → 输入 "Select Default Profile" → 选择 "Git Bash"。之后 VS Code 里的终端就和 Git Bash 一样了。

2.4 安装 Java（用于 Toxtree）

Toxtree 需要 Java。打开 Git Bash，运行 java -version，如果没有从 java.com 下载安装。

2.5 安装 R 包依赖

打开 Git Bash 或 VS Code 终端（Ctrl+`），运行：

install.packages("devtools")
devtools::install_deps()

3. 推送到远程：git push -u origin feature/你的功能名

第四步：Git 日常开发流程

4.1 每天开始工作前

在 Git Bash（Windows）或终端（macOS）里运行：

git checkout fcmsafety-v2
git pull origin fcmsafety-v2

4.2 创建功能分支（每次新任务都要这样做）

git checkout -b feature/你的功能名

# 例如：添加中国 SML 更新函数
git checkout -b feature/add-china-sml-updater

4.3 让 AI 写代码（用第三步的 Prompt）

4.4 提交改动

# 先看改动内容（重要！）
git status
git diff

# 确认正确后提交
git add .
git commit -m "feat: 添加中国SML更新函数"

# 推送到你的 Fork
git push -u origin feature/你的功能名

4.5 创建 Pull Request

  1. 打开你的 Fork 仓库页面（如 https://github.com/zhangsan/fcmsafety）
  2. 点击 Compare & pull request
  3. 确认设置：
    • base repository: QizhiSu/fcmsafety
    • base: fcmsafety-v2
    • compare: feature/你的功能名
  4. 填写标题和说明，点击 Create pull request
流程：开发 → 功能分支提交 → 推送到自己的 Fork → 创建 PR → 等待维护者审核合并

第五步：禁止做的事情

⚠️ AI 开发禁止事项（让 AI 执行命令之前先想一下）：
  • ❌ 不要删除或修改 main 分支
  • ❌ 不要强制推送 git push --force
  • ❌ 不要提交密码、密钥等敏感信息
  • ❌ 不要直接推送到 QizhiSu/fcmsafety（没有权限）
  • ❌ 不要删除重要的数据库文件或配置文件
✅ 正确做法：所有开发在 feature/你的功能名 分支上进行，推送到自己的 Fork，通过 PR 让维护者审核。

5. git push origin fcmsafety-v2

第九步：遇到问题怎么办

  1. AI 写错了代码？ 让 AI 解释代码逻辑，指出哪里不对，让 AI 重写
  2. Git 报错？ 把错误信息复制给 AI，让 AI 帮你分析
  3. 不知道从哪开始？ 让 AI 阅读 INTERN_HANDOFF.md，然后问 AI "这个项目的核心功能是什么"
  4. 不确定能不能做？ 先问 AI "这样做可以吗？"
