FCMSafety fcmsafety-v2 开发指南

食品接触材料安全评估 R 包 · fcmsafety-v2 分支实习生操作手册

第一步：账号与权限准备

重要：GitHub 仓库对没有协作者权限的账号默认是只读的。实习生需要先 Fork 自己的副本才能推送。

1.1 注册 GitHub 账号

  1. 打开 https://github.com
  2. 点击 Sign up，按提示填写用户名、邮箱、密码
  3. 验证邮箱后即可使用

1.2 Fork 仓库到自己的账号

  1. 打开仓库链接：https://github.com/QizhiSu/fcmsafety
  2. 在页面右上角点击 Fork 按钮
  3. 等待几秒，页面会跳转到「你的账号/fcmsafety」
  4. 此时你拥有了自己的可读写副本
✅ Fork 完成后，你的仓库地址类似：
https://github.com/你的用户名/fcmsafety

第二步：克隆项目并切换分支

2.1 克隆到本地

打开终端（Mac 打开「终端」应用，Windows 可用 Git Bash 或 PowerShell），运行：

# 用你自己的 Fork 地址替换下面的 URL
git clone https://github.com/你的GitHub用户名/fcmsafety.git

例如：

git clone https://github.com/zhangsan/fcmsafety.git

2.2 进入项目目录

cd fcmsafety

2.3 切换到 fcmsafety-v2 分支

git checkout fcmsafety-v2

2.4 验证当前分支

git branch -v

* fcmsafety-v2  e5b2e6d Add regulatory group matching section to handoff docs
  main          014f3d8 relocate toxic information columns
看到 * fcmsafety-v2 前面的星号，说明当前已在正确分支上。

第三步：配置 SSH（推荐，可跳过）

配置 SSH 后每次推送不需要输入用户名和密码。注意：如果使用 HTTPS 克隆，可以跳过这一步。

3.1 检查是否有 SSH Key

cat ~/.ssh/id_ed25519.pub 2>/dev/null || cat ~/.ssh/id_rsa.pub 2>/dev/null || echo "NO_KEY"

3.2 如果没有，生成新 Key

ssh-keygen -t ed25519 -C "your_email@example.com" -f ~/.ssh/id_ed25519 -N ""

3.3 复制公钥到 GitHub

cat ~/.ssh/id_ed25519.pub

复制输出的内容，进入 GitHub → 右上角头像 → Settings → SSH and GPG keys → 点击 New SSH key，粘贴公钥。

3.4 修改 remote 为 SSH 地址（可选）

git remote set-url origin git@github.com:你的用户名/fcmsafety.git

第四步：配置本地开发环境

4.1 安装 R

  1. 访问 https://cran.r-project.org/
  2. 选择适合你系统的版本下载并安装

4.2 安装 RStudio（推荐）

  1. 访问 https://posit.co/download/rstudio-desktop/
  2. 下载并安装 RStudio Desktop

4.3 在 RStudio 中打开项目

  1. RStudio → File → Open Project
  2. 选择项目目录中的 fcmsafety.Rproj

4.4 安装 R 包依赖

在 RStudio 的 Console 中运行：

# 安装 devtools（如果提示没有安装）
install.packages("devtools")

# 安装 fcmsafety 的所有依赖
devtools::install_deps()
⚠️ 安装依赖可能需要几分钟，请耐心等待。如果遇到报错，检查 R 版本是否太旧。

4.5 安装 Java（用于 Toxtree）

Toxtree 需要 Java 环境。macOS 用户运行：

java -version

如果没有输出或报错，从 java.com 下载安装 Java。

第五步：日常开发流程

5.1 开始工作前：拉取最新代码

git checkout fcmsafety-v2
git pull origin fcmsafety-v2

5.2 创建自己的功能分支（推荐）

不要直接在 fcmsafety-v2 上开发，建议创建功能分支：

# 从 fcmsafety-v2 创建新分支
git checkout -b feature/你的功能名

# 例如：添加一个新函数
git checkout -b feature/add-china-sml-updater

# 或修复一个问题
git checkout -b fix/update-history-query

5.3 修改代码

在 RStudio 中编辑 R/ 目录下的文件，或修改文档。

5.4 查看修改内容

# 查看哪些文件被修改了
git status

# 查看具体改动（推荐先看这个）
git diff

5.5 提交修改

# 添加要提交的文件（. 表示所有修改）
git add .

# 提交，写清楚改动内容
git commit -m "Add function: update_china_sml()"

# 或者更规范的格式：
git commit -m "feat: add China SML update function"
提交信息规范建议：
  • feat: 新功能
  • fix: 修复 bug
  • docs: 文档修改
  • refactor: 重构（不改变功能）
  • chore: 杂项（构建脚本、依赖更新等）

5.6 推送到自己的 Fork

# 第一次推送功能分支
git push -u origin feature/你的功能名

# 之后的推送
git push

5.7 在 GitHub 上创建 Pull Request

  1. 打开你的 Fork 仓库页面（如 https://github.com/zhangsan/fcmsafety）
  2. 会自动提示「Compare & pull request」或点击 Compare across forks
  3. 确认：
    • base repository: QizhiSu/fcmsafety
    • base: fcmsafety-v2
    • head repository: 你的用户名/fcmsafety
    • compare: feature/你的功能名
  4. 填写 PR 标题和说明，点击 Create pull request

第六步：同步上游最新更新

在开发过程中，原仓库（QizhiSu/fcmsafety）可能有新提交。需要定期同步：

6.1 添加上游仓库地址

# 添加上游仓库（只需做一次）
git remote add upstream https://github.com/QizhiSu/fcmsafety.git

# 验证
git remote -v
origin    https://github.com/你的用户名/fcmsafety.git (fetch)
origin    https://github.com/你的用户名/fcmsafety.git (push)
upstream  https://github.com/QizhiSu/fcmsafety.git (fetch)
upstream  https://github.com/QizhiSu/fcmsafety.git (push)

6.2 拉取上游 fcmsafety-v2 的最新代码

# 切换到 fcmsafety-v2
git checkout fcmsafety-v2

# 拉取上游更新并合并
git fetch upstream
git merge upstream/fcmsafety-v2

# 如果有冲突，手动解决后再 commit
git add .
git commit -m "Merge upstream fcmsafety-v2"

6.3 把同步后的更新推送到自己的 Fork

git push origin fcmsafety-v2

6.4 更新功能分支（如果有未完成的开发）

git checkout feature/你的功能名
git rebase fcmsafety-v2
⚠️ rebase 会改变提交历史。如果你的功能分支已经推送到远程并有人查看过，不要 rebase。

第十步：遇到问题怎么办

10.1 Git 相关问题

问题解决方法
merge conflict（合并冲突） 打开冲突文件，搜索 <<<<<<<，保留想要的代码，删除冲突标记，然后 git add . && git commit
误删文件想恢复 git checkout HEAD -- 文件名
想撤销上一次 commit git reset --soft HEAD~1（保留改动）或 git reset --hard HEAD~1（完全撤销）
不知道当前在哪个分支 git branch 或看 RStudio 右下角
push 被拒绝（远程有新提交） 先 git pull --rebase，解决冲突后再 git push

10.2 R 包相关问题

问题解决方法
包加载失败，提示缺少某个包 install.packages("包名")
包行为异常 先 devtools::document() 重新生成文档，再 devtools::load_all()
数据库打不开 检查 inst/fcmsafety.db 是否存在，运行 initialize_database() 重新初始化
测试不通过 运行 devtools::test(reporter = "verbose") 查看详细错误信息

10.3 求助方式

  1. 先自己搜索错误信息（复制错误信息的关键词）
  2. 查看 INTERN_HANDOFF.md 中是否有相关说明
  3. 在 GitHub 上提交 Issue 描述问题，附上错误信息和你的操作步骤
  4. 如果是在职人员，可以联系项目维护者
